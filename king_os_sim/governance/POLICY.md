# Governance policy (synthetic control plane)
1. Every experiment MUST have a preregistration in `preregistrations/` dated BEFORE any results exist.
2. Acceptance criteria (thresholds) MUST NOT be changed after results are seen.
3. Every claim in `decision_log.md` MUST be supported by an evidence file in `evidence/` that is valid JSON.
4. Changes to this policy require King's explicit approval (CODEOWNERS review). Workers may never edit it directly.
